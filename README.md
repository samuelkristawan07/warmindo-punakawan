## 🚀 Cara Menjalankan Secara Lokal
Buka berkas `index.html` langsung di browser, atau jalankan melalui web server lokal:
```bash
# Menggunakan python
python -m http.server 8000

# Atau menggunakan Node / npm
npm start
```
Buka browser pada `http://localhost:8000`.
